# Face landmarks

`face_landmarker.task` is the official Google MediaPipe float16 v1 model:
https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

Used locally in the browser to guide selfie capture. It does not establish identity
or spoof resistance. WASM assets are bundled from the installed tasks-vision package.
Documentation: https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker
