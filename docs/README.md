# Hamtry баримт бичиг

Хүн болон agent өөр өөр дарааллаар уншина. Баримт нь одоо ажиллаж байгаа
кодыг тайлбарлана; ирээдүйд хийх ажлыг хэрэгжсэн мэт бичихгүй.

- **Оюутан, багийн гишүүд:** [docs/human](human/README.md) — Монгол тайлбар, class-ийн хичээл, ашиглах жишээ.
- **Код өөрчлөх agent:** [docs/agents](agents/README.md) — архитектур, API гэрээ, ажлын хил, шалгалт.

Одоогийн санг `@hamtry/library` гэж импортлоно. Энэ нь Hamtry төслийн local
alias бөгөөд npm дээр нийтлэгдсэн package биш. Сан нь native Web Components,
өөрсдийн reactive framework, Hamtry design system-ээс бүрдэнэ. React editor
тусдаа `/editor.html` дээр байна.

Next: [UX/UI roadmap](human/roadmap.md), [folder structure](human/folder-structure.md), and [agent implementation plan](agents/roadmap.md).
