# Хот доторх таны булан — 3D ертөнц

`/explore.html` дээр Three.js-ээр байгуулсан Улаанбаатарын жижиг,
уран сэтгэмжит ертөнц бий. Нүүрийн **3D ертөнц** холбоосоор орно.

1. Барилга эсвэл доорх гурван сонголтоос очих газраа сонгоно.
2. **Энд очъё** дарахад дүртэй машин богино замаар явна. **Шууд очих**
   товчоор аяллыг алгасаж болно. Өөр газар сонгох эсвэл Escape дарах нь зогсооно.
3. Ирсний дараа хаалгаар орно. Доторх тавилга нь вэбийн удирдлага болно.
4. Кафены цэс → хамтрагчид; буйдан, галерейн зураг → өрөөнүүд;
   номын тавиур → хадгалсан сонголтууд; ажлын ширээ → өрөө санал болгох.
5. Гэрэл → өдөр/оройн орчин; хаалга → хот руу буцах.

Сцен дээрх бүх үндсэн үйлдэл доорх HTML товчоор давхар ажиллана.
Tab, Enter/Space-ээр удирдаж, Escape-ээр цонх хаана. Хот/өрөө солиход
focus дараагийн удирдлага руу очно. Browser Back болон өрөөний шууд холбоос ажиллана.

**Тохиргоо** хэсэгт хөдөлгөөн багасгах, чанар сонгох боломжтой. Хөдөлгөөн
багасгасан үед замын анимацгүй шууд орно. Автомат горим жижиг дэлгэц дээр
нягтаршлыг бууруулж сүүдэр унтраана. Хөдөлгөөнгүй үед renderer frame дахин
зурдаггүй; хуудас харагдахгүй үед аяллын frame зогсоно. Шинэ том library нэмээгүй:
манай native компонент, signal engine, суулгасан Three.js-ийг ашигласан.

Сцен нь бодит хаяг эсвэл Улаанбаатарын нарийн газрын зураг биш. Кафе, галерей,
өрөөнүүд нь хичээлийн туршилтын жишээ. Зүрхэн товчийн хадгалалт нүүрийн
хадгалсан сонголттой ижил энэ хөтөчийн өгөгдөл ашиглана; бодит бүртгэл биш.
Explore-ийн өнгө тусдаа хүрээнд үйлчилнэ, shared theme JSON-ийг өөрчлөхгүй.

Кодын бүтэц, GPU cleanup: [agent contract](../agents/explore.md).

## Impeccable Live

Impeccable-ийн **Live** нь хөгжүүлэлтийн хуудсанд ажиллана:
`http://127.0.0.1:5173/explore.html`. `4173` нь бэлэн build-ийн preview тул
source засвар шууд харагдахгүй. **DESIGN.md** самбарт өнгө, бичиглэл, компонентууд
харагдана; **Steer** хэсэгт өөрчлөх зүйлээ бичиж болно.

Live эхлэхэд `context_missing` гарвал `DESIGN.md`, `config_missing` гарвал
`.impeccable/live/config.json` дутуу байна. Энэ хоёр файл одоо client хавтсанд бий.
Explore-ийн **Pick** нь одоогоор бүхэл `hamtry-explore` элементийг сонгодог;
доторх гарчиг, тавилгын удирдлагыг өөрчлөхөд **Steer** ашиглана.
Live session-ийг агент ажиллаж байх үед ашиглаж, дуусахдаа **Exit** дарна.
