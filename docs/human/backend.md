# Hamtry backend

Backend нь Cloudflare Workers дээрх Hono, D1 өгөгдлийн сан, R2 зургийн хадгалалтаас бүрдэнэ. Өгөгдөлд SQL хүсэлтээр хандана; ORM ашиглахгүй.

Профайлын товчоор бүртгүүлж, нэвтэрнэ. Нэвтэрсэн хэрэглэгчийн хадгалсан сонголт бүртгэлтэй нь холбогдоно. Өрөөний мэдээлэл, нүүх боломжтой өдөр, байршил, зургаа оруулаад урьдчилан харна. “Зар нийтлэх” товчийг дарсны дараа бусад хэрэглэгчид харагдана. Зураг бэлтгэх ажил worker дээр хийгдэнэ. Шалгалт дутуу бол нийтлэхгүй.

Backend холбогдоогүй үед хөтөчийн жишээ горим ажиллана. Өмнө нь зөвхөн тухайн хөтөчид хадгалсан зарыг нэвтрэх үед автоматаар нийтлэхгүй. Нэвтрэх эрх, зарын эзэмшил, нийтлэх зөвшөөрлийг сервер шалгана.

Selfie-ийн хөдөлгөөнийг browser worker шалгаж, эцсийн liveness үр дүнг Python сервер буцаана. Шалгалт бүр нэвтэрсэн хэрэглэгчтэй холбогдоно. Энэ үр дүн нь иргэний үнэмлэхээр таньсан баталгаа биш.

И-мэйл хүргэлт, нууц үг сэргээх и-мэйл, чат болон өөрийгөө танилцуулах зарын UI дараагийн ажилд үлдсэн. Classroom жишээ зарууд бодит хэрэглэгч, баталгаажуулалт биш.
